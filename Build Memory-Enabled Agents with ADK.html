The Scenario

You're the support lead at Lumen & Co., a smart-lamp company.
Your agent is Iris. Your customer is Maya, and her LumenGlow v2 flickers.

Iris starts with all five memory failures in place. You fix them — one task, one # TODO: prefix at a time.

The Five Memory Failures

1"What was your order number again?" — re-asking within a chat
2"You've been transferred. Please describe your issue from the beginning." — losing context at handoff
3"Welcome! How can I help you today? 😊" — forgetting a returning customer
4"Could you describe the damage?" — after you already sent a photo
5"We've never seen this issue." — missing what the whole company already knows

What You'll Learn

  • ✓tool_context.state — the channel your code reads, next to the transcript the model reads
  • ✓LongRunningFunctionTool + FunctionResponse — parking a run for a human
  • ✓add_session_to_memory / search_memory — a write policy and a recall policy you write
  • ✓Connecting Vertex AI Memory Bank on an Agent Engine instance
  • ✓save_artifact — giving an upload a home, extracting facts into state
  • ✓Semantic search over BigQuery with embeddings generated in place

A vector here is just a list of 3072 numbers describing what a sentence means , so two tickets land near each other when they describe the same problem in different words — which is exactly what InMemoryMemoryService could not do back in Task 5, where it scored memories by counting shared words.
